HTML Advanced - SmileSchool Homepage
About the Project
This project recreates the structure of the SmileSchool homepage from a Figma design file, using semantic HTML5 only — no CSS, no inline styling. The goal is to translate a visual design into meaningful, well-structured markup that reflects the actual content hierarchy of the page, independent of how it looks.

Page Overview
The homepage includes the following sections:

Header — logo, navigation, hero heading ("Get schooled"), a call-to-action button, and a row of featured mentors
Testimonial — a quote from a satisfied user
Most Popular Tutorials — a set of tutorial cards with ratings and instructor credit
Free Membership — a highlighted section listing membership perks with a call-to-action
F.A.Q. — frequently asked questions in a two-column layout
Footer — logo, social media links, and copyright

Why Semantic HTML
Gives meaning to content for browsers, search engines, and assistive technologies
Keeps structure and presentation separated — CSS styling comes in a later project
Improves accessibility and long-term maintainability
