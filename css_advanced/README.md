CSS Advanced - SmileSchool Homepage
About the Project
This project builds directly on the semantic HTML structure from html_advanced and adds full CSS styling to recreate the SmileSchool homepage design pixel-for-pixel from the provided Figma file. Where html_advanced focused purely on structure, this project focuses on layout, color, typography, and spacing.

Page Overview
The homepage includes:

Header — logo and navigation
Banner — hero heading, tagline, CTA button, and featured mentors
Testimonial — a styled quote block
Most Popular Tutorials — a styled card grid
Free Membership — a highlighted CTA section
F.A.Q. — a two-column layout
Footer — logo, social links, and copyright
Design Reference
SmileSchool homepage design

Design provided via Figma. Font values were rounded where floats were given, and missing fonts (Source Sans Pro, Spin Cycle OT) were sourced separately.
